# FlyRank A8 — PDF Report Generator

## Description

A backend service that generates PDF reports for a bookstore dataset. Book
data (scraped and validated in A9) is seeded into a SQLite database, aggregated
with SQL queries, rendered into an HTML report, and converted to a PDF using
Playwright/Chromium. A FastAPI service exposes endpoints to trigger report
generation, check report status, and download the resulting PDF.

## Tech Stack

- **Python 3**
- **FastAPI** — REST API
- **SQLite** — storage for book data and report metadata (`report.db`)
- **Playwright (Chromium)** — headless HTML-to-PDF rendering
- **JSON** — source dataset (`books.json`)

## Database and Seed

### `books` table schema

```sql
CREATE TABLE IF NOT EXISTS books (
    id INTEGER PRIMARY KEY AUTOINCREMENT,
    title TEXT NOT NULL,
    price REAL NOT NULL,
    rating INTEGER NOT NULL,
    url TEXT NOT NULL
)
```

### `reports` table schema

```sql
CREATE TABLE IF NOT EXISTS reports (
    id INTEGER PRIMARY KEY AUTOINCREMENT,
    status TEXT NOT NULL,
    file_path TEXT,
    created_at TEXT NOT NULL
)
```

### Seeding process

`seed.py` reads `books.json`, maps the text rating (`"One"`–`"Five"`) to
an integer (`1`–`5`), and inserts each book into the `books` table with its
`title`, `price`, `rating`, and `url`.

Before inserting, the seed script runs:

```sql
DELETE FROM books
```

This clears any existing rows first, so the script is **safe to re-run**
without creating duplicate entries.

## SQL / Report Aggregation

All aggregation logic lives in `report_queries.py`.

**Total number of books**
```sql
SELECT COUNT(*) FROM books
```

**Average price**
```sql
SELECT AVG(price) FROM books
```

**Top 5 most expensive books**
```sql
SELECT title, price
FROM books
ORDER BY price DESC
LIMIT 5
```

**Books grouped by rating**
```sql
SELECT rating, COUNT(*)
FROM books
GROUP BY rating
ORDER BY rating
```

`get_report_data()` calls all four functions above and returns a single
dictionary:

```python
{
    "total_books": ...,
    "average_price": ...,
    "top_5_expensive_books": [...],
    "books_by_rating": [...]
}
```

## HTML and PDF Generation

`pdf_generator.py` builds the report:

- `build_html(report)` assembles an HTML page with:
  - Summary cards for **total books** and **average price**
  - A table of the **top 5 most expensive books**
  - A table of **books grouped by rating**
  - A table of **all books** (title, price, rating, URL), queried separately
    via `get_all_books()`
- The stylesheet sets `tr { break-inside: avoid; page-break-inside: avoid; }`
  so table rows are not split across pages, and `thead { display:
  table-header-group; }` so table headers repeat on each page.

- `generate_pdf(html, output_path)` uses Playwright to launch headless
  Chromium, load the HTML with `page.set_content(html)`, and export it with:

```python
await page.pdf(
    path=output_path,
    format="A4",
    print_background=True
)
```

## FastAPI API

All endpoints are defined in `main.py`.

### `GET /health`

Basic health check.

**Response `200`**
```json
{ "status": "ok" }
```

### `POST /reports`

Generates a new report, or returns today's existing report if one has
already been created (see Idempotency below).

**Request:** no body required.

**Response `201`** (new report created)
```json
{
    "id": 1,
    "status": "done",
    "file": "/reports/1/file"
}
```

**Response `201`** (existing report for today returned)
```json
{
    "id": 1,
    "status": "generating",
    "file": "/reports/1/file"
}
```

### `GET /reports/{report_id}`

Returns the status and metadata of a specific report.

**Response `200`**
```json
{
    "id": 1,
    "status": "done",
    "file_path": "reports/report_1.pdf",
    "created_at": "2026-08-26T10:15:00",
    "file": "/reports/1/file"
}
```

**Response `404`** — if `report_id` does not exist:
```json
{ "detail": "Report not found" }
```

### `GET /reports/{report_id}/file`

Downloads the generated PDF for a report.

**Response `200`** — returns the PDF file (`application/pdf`) as a file
download, not embedded in JSON.

**Response `404`** — if the report or its file does not exist:
```json
{ "detail": "Report not found" }
```
or
```json
{ "detail": "Report file not found" }
```

## PDF File Serving

Generated PDFs are written to the `reports/` directory using the filename
pattern `report_{report_id}.pdf`. The `/reports/{report_id}/file` endpoint
serves the PDF directly as a file response (`FileResponse`), not as JSON or
base64 data.

## Idempotency

`POST /reports` checks whether a report record already exists for **today's
date** (`DATE(created_at) = today`) before creating a new one:

- If a report for today exists, its record is returned as-is (no new PDF is
  generated, and its `status` field is returned exactly as stored — this may
  be `"generating"` or `"done"` depending on what was last saved).
- If no report exists for today, a new database record is created, the PDF
  is generated, and the record is updated to `status = "done"`.

This means at most one report is generated per calendar day; repeated calls
to `POST /reports` on the same day do not create duplicate PDF files.

## Running the Complete Project

```bash
# 1. Activate the environment
source venv/bin/activate

# 2. Seed the books table
python seed.py

# 3. Create the reports table
python report_database.py

# 4. Start the API
uvicorn main:app --reload

# 5. Generate and download a report
curl -X POST http://127.0.0.1:8000/reports
curl http://127.0.0.1:8000/reports/1/file --output report.pdf
```
